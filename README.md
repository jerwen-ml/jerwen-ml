## Featured Project

### Smart Visual Schedule
[Explore project →](https://github.com/jerwen-ml/smart-visual-schedule)

A teacher-guided classroom prototype designed to bring structure and clarity to learning activities through a visual interface.

Highlights:
- Current and next activity previews
- Adjustable timers and optional spoken instructions
- Teacher-controlled completion tracking
- Schedule restart and CSV logging
- Editable activities and saved browser settings

Built with: HTML, CSS, JavaScript  
Stage: Laptop prototype for classroom testing with fictional learner codes
